# MAA-Shader

**シネマティック＆リアル、かつ圧倒的に軽量なMinecraft影MOD（シェーダーパック）**

`MAA-Shader` は、Iris / Oculus / OptiFine に対応した軽量・高完成度のシェーダーパックです。従来の影MODで課題になりやすかった「洞窟や日陰が真っ暗で遊べない」「手持ち光源がカクつく」「ブロックで囲んだ光源の指向性がない」「反射やGIを入れると重い」という問題を解決するために設計されています。

---

## 主な特徴

1. **多様な光源と筒状遮蔽（指向性ブロックライト）**
   - **ディレクショナルライト（太陽・月）**: 距離に応じて根元はくっきり、離れると柔らかくボケる接触硬化シャドウ（PCSS）＋ステンドグラスの色付き透過影。
   - **ポイントライト＆筒状遮蔽**: 光源ブロックをそのまま置けば全方位に広がり、筒のように4方向をブロックで囲んだ場合は**3Dライトマップ勾配解析＋4ステップ遮蔽レイ**によって開口部方向へ光が伸び、壁面側は遮光されます。
   - **手持ち光源（ハイブリッド / ポイント / スポットライト切替可能）**: 懐中電灯のような前方スポットライト照射と全方位ポイントライトに対応。時間軸指数平滑化（Temporal Smoothing）により、歩行時や持ち替え時の光の変化が滑らかです。

2. **色付き光源による反射光・間接光バウンス（SSGI）・色付き霧**
   - 松明・ランタン（暖色アンバー）、魂の松明・魂のランタン（青緑シアン）、レッドストーン（深紅）、溶岩（紅蓮オレンジ）、シーランタン（アクア）、エンドロッド・アメジスト（紫白）の色を判別。
   - **間接光バウンス（SSGI）**: 光が当たった壁や床、色付き羊毛などから周囲のブロックへ色付きの反射光（カラーブリーディング）が跳ね返ります。
   - **鏡面反射（SSR）＆スペキュラ**: 水面、金属・磨かれたブロック、雨天時の濡れた地面が光源の色をリアルに反射します。
   - **色付きボリューメトリックフォグ**: 光源の色が周囲の霧や空気感に溶け込みます。

3. **暗くなりすぎないシネマティック・リアル設計**
   - **半球スカイライト＋地面照り返し＋暗所最低輝度フロア**: 日陰や松明のない洞窟でも真っ黒に潰れず、立体感を保ったまま視認できます。
   - **動的明暗順応（Auto-Exposure）＋改良型ACESトーンマッピング**: 暗い場所に入ると自然に目が慣れ、明るい屋外では白飛びを抑えた映画的な階調を描画します。

4. **徹底した軽量設計**
   - 歪みシャドウマップ（Distorted Shadow Map）により、低解像度でもプレイヤー周囲の影を高精細に描画。
   - Interleaved Gradient Noise（IGN）ディザリング＋エッジ保持バイラテラルフィルタにより、最小限のレイステップ数でノイズのない滑らかな間接光・ゴッドレイを実現。
   - シェーダー設定から `軽量 (Low)` / `標準 (Medium)` / `高品質 (High)` / `最高品質 (Ultra)` をワンクリックで切り替え可能。

---

## 導入方法

1. **Iris Shaders**（推奨・Fabric/NeoForge）または **OptiFine** を導入した Minecraft を用意します。
2. このリポジトリフォルダごと（`MAA-Shader` フォルダのまま、または中身を `MAA-Shader.zip` に圧縮して）Minecraft の `shaderpacks` フォルダに配置します。
   - 構成：`shaderpacks/MAA-Shader/shaders/...`
3. ゲーム内の「ビデオ設定」→「シェーダー詳細な設定（Shader Packs）」から **MAA-Shader** を選択して適用します。
